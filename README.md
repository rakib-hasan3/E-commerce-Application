1) What is the difference between null and undefined?
Ans:null এবং undefined-এর মধ্যে পার্থক্য কী?
সহজ কথায়, undefined মানে হলো কোনো কিছু এখনো ঠিক করা হয়নি, আর null মানে হলো আপনি নিজে ইচ্ছা করে সেটাকে খালি রেখেছেন।

undefined: যখন আপনি একটি ভেরিয়েবল ডিক্লেয়ার করেন কিন্তু কোনো ভ্যালু দেন না, তখন জাভাস্ক্রিপ্ট নিজে থেকেই তাকে undefined ধরে নেয়। (যেমন: let x;)

null: এটি একটি অ্যাসাইনমেন্ট ভ্যালু। আপনি যখন বোঝাতে চান যে এই ভেরিয়েবলটি বর্তমানে খালি বা এর কোনো ভ্যালু নেই, তখন আপনি null ব্যবহার করেন। (যেমন: let y = null;)

2) What is the use of the map() function in JavaScript? How is it different from forEach()?
Ans:map() ফাংশনের কাজ কী? এটি forEach() থেকে কীভাবে আলাদা?
উভয়ই অ্যারের (Array) ওপর লুপ চালানোর জন্য ব্যবহৃত হয়, কিন্তু তাদের উদ্দেশ্য ভিন্ন:

map(): এটি একটি অ্যারের প্রতিটি উপাদানের ওপর কাজ করে একটি নতুন অ্যারে তৈরি করে এবং সেটি রিটার্ন করে। এটি মূল অ্যারে পরিবর্তন করে না।

forEach(): এটি শুধু লুপ চালায় এবং প্রতিটি উপাদানের জন্য কিছু কাজ করে (যেমন: কনসোলে প্রিন্ট করা)। এটি কোনো কিছু রিটার্ন করে না।

3) What is the difference between == and ===?
Ans:এটি জাভাস্ক্রিপ্টের খুব কমন একটি প্রশ্ন:

== (Loose Equality): এটি শুধু ভ্যালু বা মান চেক করে। ডাটা টাইপ আলাদা হলেও যদি মান এক হয়, তবে এটি true দেয়। (যেমন: 5 == "5" ফলাফল দেবে true)

=== (Strict Equality): এটি ভ্যালু এবং ডাটা টাইপ—উভয়ই চেক করে। তাই এটি বেশি নিরাপদ। (যেমন: 5 === "5" ফলাফল দেবে false, কারণ একটি নাম্বার আর অন্যটি স্ট্রিং)


4) What is the significance of async/await in fetching API data?
Ans:API ডাটা ফেচ করার ক্ষেত্রে async/await-এর গুরুত্ব কী?
আগে API থেকে ডাটা নিতে .then() এবং .catch() ব্যবহার করা হতো, যা অনেক সময় কোডকে জটিল (Callback Hell) করে ফেলত।

সহজপাঠ্যতা: async/await ব্যবহার করলে এসিনক্রোনাস (Asynchronous) কোড দেখতে সাধারণ সিনক্রোনাস কোডের মতো মনে হয়।

সুবিধা: এটি কোডকে পরিষ্কার রাখে এবং এরর হ্যান্ডলিং (try/catch দিয়ে) করা অনেক সহজ করে দেয়। কোড পড়ার সময় কনফিউশন কম হয়।

5) Explain the concept of Scope in JavaScript (Global, Function, Block).
Ans:Scope (স্কোপ) কী? (Global, Function, Block)
স্কোপ ঠিক করে যে আপনি একটি ভেরিয়েবল কোডের কোথা থেকে ব্যবহার করতে পারবেন।

Global Scope: যদি কোনো ভেরিয়েবল সব ফাংশনের বাইরে লেখা হয়, তবে সেটি কোডের যেকোনো জায়গা থেকে ব্যবহার করা যায়।

Function Scope: একটি ফাংশনের ভেতরে ডিক্লেয়ার করা ভেরিয়েবল শুধু ওই ফাংশনের ভেতরেই কাজ করবে। বাইরে থেকে তাকে পাওয়া যাবে না।

Block Scope: { } সেকেন্ড ব্র্যাকেটের ভেতরে (যেমন: if বা for লুপের ভেতর) let বা const দিয়ে ডিক্লেয়ার করা ভেরিয়েবল শুধু ওই ব্লকের ভেতরেই কাজ করে।
